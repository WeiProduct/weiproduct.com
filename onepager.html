Building personal AI that understands the whole person: 18 focused iOS apps working as specialized agents that feed one shared personal context layer.

Investment thesis

  • Multi-agent context engine. Focused apps act as specialized agents that capture different life signals while sharing design, support, and system infrastructure.
  • Fast learning loop. Launch narrow agents into real daily workflows, learn from usage, and double down on what people return to.
  • Whole-person decision layer. Connected signals across productivity, finance, learning, wellness, and utility become one decision layer — built by a CS + economics founder.

The system today — 18 agents, all live on the App Store

How it's built

  • SwiftUI clients — 18 focused iOS appsOn-device data first · one shared design system
  • ↓ HTTPS — requests only, never credentials
  • Hardened serverless proxies — one per appAPI keys held server-side, never shipped in binaries
  • ↓ scoped model calls
  • Model layerOpenAI · Whisper · Gemini — swappable per agent
